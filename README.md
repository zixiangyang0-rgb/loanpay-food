# LoanPay Kitchen — food.loanpaylogic.com

A warm, magazine-style food publication in the LoanPay Logic network: 25 original cooking guides plus 5 legal pages, built with Next.js 15 + React 19 + Tailwind 4 + TypeScript.

## Develop

```bash
npm install --no-audit --no-fund
npm run dev
npx tsc --noEmit
```

## Content

25 guides: meal prep, high-protein meals, cheap healthy meals, air fryer, cast iron, meal planning, freezer meals, one-pot, 30-minute dinners, snacks, smoothies, salads, budget groceries, pantry staples, food storage safety, leftover safety, slow cooker, pressure cooker, baking basics, sourdough starter, eggs, pasta, rice cooker, kitchen tools, recipe cost calculator.

Nutrition figures reference public USDA data (FoodData Central, FoodSafety.gov). Allergen reminders included. General education only — not medical or nutrition advice.
